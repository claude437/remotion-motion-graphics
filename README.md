# Remotion Motion Graphics

Programmatic motion graphics videos with [Remotion](https://www.remotion.dev) **4.0.534**, set up for
working with AI coding agents. Videos are React components, previewed live in Remotion Studio and rendered to MP4.

The sample composition **Showcase** (1920×1080, 30 fps, 12.1 s) has staggered typography, spring-animated
shapes, self-drawing SVG paths, slide and fade scene transitions, a music bed and transition sound effects synced
to the timeline.

## Requirements

- A current LTS release of Node.js with npm (tested with Node 22.22 and npm 10.9)
- Rendering downloads Chrome Headless Shell automatically the first time (or run `npx remotion browser ensure`)

## Commands

```bash
npm install                         # install dependencies
npm run dev                         # open Remotion Studio (http://localhost:3000)
npm run new -- MyVideo --seconds=8  # scaffold + register a new composition
npm run render                      # render Showcase → out/showcase.mp4
npm run render:draft                # quick half-resolution render
npx remotion render MyVideo out/my-video.mp4 --codec=h264   # render any composition
npm run still                       # render a PNG frame
npm run compositions                # list compositions and their metadata
npm run lint                        # ESLint + TypeScript
npm run upgrade                     # upgrade Remotion packages + agent skills together
```

## VitaminDMS (vertical TikTok explainer)

A 16-second, 1080×1920, 60 fps Arabic motion-graphics explainer on Vitamin D and MS, in the MS Fighter palette.
Every object morphs into the next scene, with no hard cuts. Timing and layout live in
`src/videos/vitamin-d-ms/timeline.ts`.

```bash
npm run dev                  # then open http://localhost:3000/VitaminDMS
npm run render:vitamin-d     # → renders/vitamin-d-ms.mp4 (H.264, yuv420p BT.709, CRF 18)
```

### VitaminDMS-Part2

The 20-second continuation (1080×1920, 60 fps, 1200 frames). It opens on Part 1's final frame and reuses the same
brand system and components. Timing: `src/videos/vitamin-d-ms-part2/timeline.ts`.

```bash
npm run dev                      # then open http://localhost:3000/VitaminDMS-Part2
npm run render:vitamin-d-part2   # → renders/vitamin-d-ms-part2.mp4
```

## TayibatMS

30 seconds, 1080×1920, 60 fps, 1800 frames: why the Tayibat diet should not replace evidence-based MS care.
Fifteen 2-second scenes in one continuous morph. SFX only (no speech, no music). Timing, layout and SFX cues:
`src/videos/tayibat-ms/timeline.ts`.

```bash
npm run dev                           # then open http://localhost:3000/TayibatMS
npm run render:tayibat                # → renders/tayibat-ms-30s.mp4 (picture + SFX)
npm run render:tayibat:video-only     # → renders/tayibat-ms-30s-video-only.mp4 (no audio)
npm run render:tayibat:sfx            # → renders/tayibat-ms-30s-sfx.wav (SFX stem only)
npm run render:tayibat:cues -- 0.8    # → renders/tayibat-ms-30s-sfx-cues.csv (+ times for a 0.8× edit)
```

## Changing resolution, frame rate and duration

Edit `src/config/video.ts`:

```ts
export const VIDEO = { width: 1920, height: 1080, fps: 30 };
export const SHOWCASE_SECONDS = { intro: 4, features: 5, outro: 4.5, transitionLength: 0.7 };
```

All animation timing is written in seconds × fps, so changing `fps` keeps the motion at the same speed.
For a one-off render you can also override settings with flags:
`npx remotion render Showcase out/720p.mp4 --width=1280 --height=720`.

## Project structure

```
src/config/      video settings and theme (colors, type scale, safe area)
src/lib/         animation, audio/beat-sync, timeline and font helpers
src/components/  Background, AnimatedText, PopIn, DrawPath, FeatureCard
src/scenes/      Intro, Features, Outro (each also previewable on its own)
src/compositions/Showcase.tsx  scenes + transitions + audio
public/          fonts and audio (use staticFile())
scripts/         new-composition generator, audio generator
```

## Working with AI agents

- **`AGENTS.md`** (imported by `CLAUDE.md`) explains how to create scenes, animate type and graphics, sync audio,
  preview and render in this project.
- **`.agents/skills/remotion-best-practices`** holds the official Remotion agent skill, installed with
  `npx skills add remotion-dev/skills`. `.claude/skills` links to it for Claude Code.

Example prompt: *"Create a 10-second product launch composition with a kinetic title, three stat counters and a wipe
transition, synced to the music beat."*
