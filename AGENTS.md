# AGENTS.md: Remotion motion graphics project

Instructions for AI coding agents (Claude Code, Codex, Cursor, etc.) working in this repo.
This project makes programmatic motion graphics videos with **Remotion 4.0.534** (React 19, TypeScript, npm).

## First steps for every task

1. Load the official Remotion agent skill in `.agents/skills/remotion-best-practices/SKILL.md`
   (also linked at `.claude/skills/`). It routes to detailed guides for animation, typography,
   transitions, audio, captions, rendering and more. Follow it when it is more specific than this file.
2. Read `src/config/video.ts` (resolution, fps, scene lengths) and `src/config/theme.ts` (colors, font sizes).
3. Users may edit files between turns. If something changed unexpectedly, treat it as intentional; don't revert it.

## Project map

```
src/
  index.ts              registerRoot(): entry point, do not rename
  Root.tsx              every <Composition> is registered here
  config/video.ts       WIDTH / HEIGHT / FPS + scene lengths in seconds  ← change video settings here
  config/theme.ts       colors, font sizes, safe area, radius
  lib/animation.ts      EASE, SPRINGS, CLAMP, sec(), progress(), springIn(), stagger(), fadeInOut()
  lib/audio.ts          framesPerBeat(), beatFrame(), beatPulse(), fadeVolume()
  lib/timeline.ts       getShowcaseTimeline(): scene/transition frame positions for the sample
  lib/fonts.ts          loads Inter from public/fonts (offline-safe, blocks render until ready)
  components/           reusable building blocks (see table below)
  scenes/               one file per scene; each is also registered as its own composition
  compositions/         full videos that sequence scenes + audio (Showcase.tsx is the sample)
public/                 static assets, referenced with staticFile("path/inside/public")
  audio/                music-bed.mp3 (120 BPM), whoosh.mp3, generated by scripts/generate-audio.sh
  fonts/inter/          Inter woff2 files + OFL license
scripts/
  new-composition.mjs   `npm run new -- Name` scaffolds + registers a composition
  generate-audio.sh     regenerates the sample audio with ffmpeg
out/                    render output (git-ignored)
```

### Reusable components

| Component      | Purpose                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------- |
| `Background`   | Dark backdrop, drifting color glows, optional moving grid, vignette. Props: `glowA`, `glowB`, `grid` |
| `AnimatedText` | Word- or character-staggered reveal. `variant="rise"` (masked slide-up) or `"blur"`. `unitStyle` for gradient text |
| `PopIn`        | Springs any child (shape, logo) in with bounce + rotation, optional `float` and beat `pulse`  |
| `DrawPath`     | Draws an SVG path stroke over time (`@remotion/paths` `evolvePath`)                          |
| `FeatureCard`  | Card with self-drawing icon, title and body that rises in                                    |

Shapes come from `@remotion/shapes` (`<Circle>`, `<Rect>`, `<Triangle>`, `<Star>`, `<Polygon>`, `<Heart>`, …).

## Core rules (non-negotiable)

- **Animate only from `useCurrentFrame()`.** Use `interpolate()`, `spring()` and the helpers in `src/lib/animation.ts`.
  CSS `transition`/`animation`, Tailwind animation classes, `setTimeout`, `Date.now()` and `Math.random()` break rendering
  (use `random("seed")` from `remotion` for randomness).
- **Express time in seconds × fps.** Get `fps` from `useVideoConfig()` and write `delay={0.5 * fps}`, `[0, 2 * fps]`, etc.
  Never hard-code frame counts that assume 30 fps; the video must look the same if `VIDEO.fps` changes.
- **Clamp interpolations** with `CLAMP` (or `extrapolateLeft/Right: "clamp"`) unless overshoot is intended.
- Prefer the `scale`, `translate`, `rotate` CSS properties over `transform` strings.
- **Assets:** put files in `public/` and reference them with `staticFile()`. Never import from absolute paths.
- **Media:** use `<Audio>` / `<Video>` from `@remotion/media`, and give timed media `premountFor={fps}`.
- **Fonts:** use `THEME.font.family` (Inter, loaded in `src/lib/fonts.ts`). For another font, add woff2 files to
  `public/fonts/` and load them the same way with `@remotion/fonts`, or use `@remotion/google-fonts`
  (needs network at render time).
- **Layout:** design for video, not a web page. Keep key content inside `THEME.safeArea` (120px sides / 100px top-bottom
  at 1920×1080). Minimum sizes at 1920 wide: headline ≥ 84px, supporting text ≥ 44px; scale with width.
- Each scene must be self-contained (own `Background`, own `fontFamily`) so it previews correctly on its own.
- Install Remotion packages with `npx remotion add @remotion/<pkg>` so versions stay pinned to the same release
  as `remotion`. Never mix Remotion package versions.

## How to…

### Create a new composition

```bash
npm run new -- ProductLaunch --seconds=8
```

This creates `src/compositions/ProductLaunch.tsx` and registers it in `src/Root.tsx` above the
`new-compositions-go-above-this-line` marker. Build it out from there. To do it manually, create a component and add a
`<Composition id="..." component={...} width={VIDEO.width} height={VIDEO.height} fps={VIDEO.fps} durationInFrames={sec(8, VIDEO.fps)} />`
to `Root.tsx`. Composition IDs may contain only letters, numbers and `-`.

### Build a multi-scene video

1. One file per scene in `src/scenes/`, frame 0 = scene start (`useCurrentFrame()` is relative inside sequences).
2. Sequence scenes in `src/compositions/` with `<TransitionSeries>` from `@remotion/transitions`
   (`fade()`, `slide({direction})`, `wipe()`, `flip()`, `clockWipe()`), timing via `springTiming()` / `linearTiming()`.
   Give every `<TransitionSeries.Sequence>` a `name` and `premountFor={fps}`.
3. Transitions overlap scenes: **total = sum(scenes) − sum(transitions)**. Compute it in one place
   (see `lib/timeline.ts`) and use it for the composition's `durationInFrames`.
4. Register each scene as its own composition inside a `<Folder>` so it can be previewed in isolation.
   Use `<Series>` instead when no transitions are needed.

### Animate typography

- `<AnimatedText text="..." by="word" | "char" delay={0.3 * fps} staggerFrames={4} variant="rise" | "blur" />`
- Gradient text: pass `unitStyle={{ backgroundImage: "linear-gradient(...)", backgroundClip: "text", WebkitBackgroundClip: "text", color: "transparent" }}`.
- Underlines and scribbles: `<DrawPath d="M ..." viewBox="..." delay={...} duration={...} />`.
- Highlights, circles and strike-throughs: see the skill's `remotion-markup/text-highlights.md`.
- Measure text before fitting it: skill guide `remotion-markup/measuring-text.md`.

### Animate shapes and graphics

- Wrap `@remotion/shapes` components in `<PopIn delay={...} float={12}>` for entrance + idle motion.
- Draw strokes with `evolvePath()`; morph shapes with `interpolatePaths()` from `@remotion/paths`.
- Use `SPRINGS.smooth` for UI motion (no overshoot), `SPRINGS.bouncy` for playful pops, `EASE.out` for entrances, `EASE.in` for exits.

### Synchronize audio

- Background music: `<Audio src={staticFile("audio/music-bed.mp3")} volume={fadeVolume({...})} />` in the composition.
- Sound effects on cues: `<Audio from={cueFrame} premountFor={fps} src={staticFile("audio/whoosh.mp3")} />`, with
  cue frames from the same timeline helper that positions the scenes (see `Showcase.tsx`). Start whooshes about 0.25 s before the cut.
- Beat sync: set `MUSIC_BPM` in `config/video.ts`; `beatPulse({frame, fps, bpm})` returns 1 on each beat decaying to 0.
  Multiply scales or glows by it. `beatFrame(n, fps, bpm)` gives the frame of beat *n* for timing entrances.
- Trim with `trimBefore` / `durationInFrames`; delay with `from`. Values are in frames.
- Voiceover, captions and audio visualization: see the skill's `remotion-markup/voiceover.md`,
  `remotion-captions/`, and `remotion-markup/audio-visualization.md`.

### Change resolution, frame rate or duration

- Everything: edit `VIDEO` in `src/config/video.ts`. Scene lengths: `SHOWCASE_SECONDS` (seconds).
- One-off override at render time: `npx remotion render Showcase out/x.mp4 --width=1280 --height=720 --fps=60 --duration=300`
  (`--duration` is in frames; changing `--fps` alone does not rescale the duration).
- Non-16:9 formats (e.g. 1080×1920) need layout changes in the scenes; check every scene in Studio.

### Preview

```bash
npm run dev            # Remotion Studio at http://localhost:3000 (opens a browser)
npx remotion studio --no-open   # agents with an in-app browser: open the printed URL yourself
```

Open a composition directly at `http://localhost:3000/<CompositionId>`. Studio hot-reloads on save.
Keep Studio running while editing so the user can watch and steer. Don't render unless the user asks for a file.

### Verify your work (before saying a task is done)

```bash
npm run lint                                         # ESLint (Remotion rules) + TypeScript
npx remotion compositions                            # all compositions resolve with correct metadata
npx remotion still Showcase out/check.png --frame=90 # render a single frame and look at it
```

When reviewing frames, check that text stays inside the safe area, nothing overlaps unintentionally, and the last
frame looks intentional. Check several frames per scene with `npx remotion render <Id> out/frames --sequence --frames=0-90 --every-nth-frame=15 --image-format=jpeg`.

### Render

```bash
npm run render                 # Showcase → out/showcase.mp4 (H.264 + AAC)
npm run render:draft           # half resolution, fast
npx remotion render <CompositionId> out/<name>.mp4 --codec=h264 [--crf=18]
npm run still                  # PNG of frame 60
```

The first render downloads Chrome Headless Shell automatically (`npx remotion browser ensure` does it ahead of time).
On machines without internet, pass `--browser-executable=/path/to/chrome-headless-shell`.
